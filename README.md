# AI Study Behavior Intelligence Platform

## Overview

This project is an AI-powered behavioral analytics platform that analyzes study habits, sleep patterns, and productivity trends to predict burnout risk and forecast future performance.

The system uses machine learning, time-series forecasting, and interactive dashboards to generate actionable productivity insights.

---

## Features

- Study behavior data simulation
- Productivity prediction using Random Forest
- Burnout risk classification
- Weekly performance reports
- PDF report generation
- Smart recommendations engine
- Burnout alert system
- Time-series productivity forecasting
- Interactive Streamlit dashboard

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Statsmodels (ARIMA)
- Matplotlib
